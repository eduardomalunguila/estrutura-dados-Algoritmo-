# estrutura-dados-Algoritmo-
trabalho de estrutura de dados(pilha e fila)

Descrição
Este trabalho foi desenvolvido no ambito da disciplina de Algoritmo e Estrutura de Dados.

Objectivo do projecto:
Pila:
1. Ampliar o conhecimento sobre algoritmo e Estrutura de dados
2. conhecer como fazer a inserção(push) de um elemnto dentro duma pilha;
3. permitir fazer remoção de elemento(pop) dentro da pilha;
4. mostrar como consultar elemento no topo(top);
5. analisar se a pilha esstá vazia(isEmpty).
Fila:
1. Mostrar como inserir elemento(queu);
2. Mostrar como remover elemento(enque);
3. conhecer como visualizar/consultar elemento (font/peek);
4. verificar se está vazia(isEmpty):

Como executar o Projecto:
1. Instalar o aplicativo Netbean ou Intelij que permite rodar programas JAVA;
2. Ao entrar na pasta completa do projecto, poderá escolher uma das pastas pretendidas: Fila ou Pilha
Funcionalidade do projecto:

Pilha: Ao executar o projecto, ele abri este menu que é a tela principal, onde cada número representa uma operação/instrução. Ela obedece a regra LIFO (LAST -IN - FIRST-OUT)
========== MENU PRINCIPAL DA PILHA ==========="
      1. ADICIONAR ELEMENTO
      2. REMOVER ELEMENTO
      3. VISUALIZAR NO TOPO
      4. VISUALIZAR SE ESTA VAZIA
      0. FECHAR O PROGRAMA
Fila:  Ao executar o projecto, ele abri este menu que é a tela principal, onde cada número representa uma operação/instrução:Obedece a regra FIFO (FIRST - IN- FIRST - OUT).
  ======== MENU FILA =========
          1. Adicionar
          2. Remover
          3. Ver o elemento que está em frente
          4. Ver se está vázia");
          0. Fechar do programa
